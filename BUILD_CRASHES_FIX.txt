❌ PROBLEM: Script closes immediately or crashes when pressing keys
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


✅ SOLUTION 1: Use the Simple Script (No Key Presses)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Instead of build-apk.bat, use:

    build-apk-simple.bat

This runs straight through without asking you to press any keys.


✅ SOLUTION 2: Run in PowerShell Instead
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Right-click in project folder
2. Choose "Open in Terminal" or "Open PowerShell here"
3. Type: .\build-apk.ps1
4. Press Enter


✅ SOLUTION 3: Run Commands Manually (Most Control)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open PowerShell in your project folder and run one at a time:

    npm run build

Wait for it to finish, then:

    npx cap sync android

Wait for it to finish, then:

    cd android
    .\gradlew.bat assembleDebug

Wait 5-10 minutes. Your APK will be at:
android\app\build\outputs\apk\debug\app-debug.apk


✅ SOLUTION 4: Use GitHub Actions (No Local Build)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Build in the cloud - no local issues!

1. Push to GitHub:
   git add .
   git commit -m "Build APK"
   git push

2. On GitHub: Actions → Build Android APK → Run workflow

3. Download APK from Artifacts after 5-10 minutes


🔍 COMMON CRASH CAUSES
━━━━━━━━━━━━━━━━━━━━━

❌ Java not installed
   → Install from: https://adoptium.net/temurin/releases/
   → Restart computer after install

❌ Node.js not installed
   → Install from: https://nodejs.org

❌ Running from wrong folder
   → Make sure you're in the project root folder
   → The folder should have: package.json, android folder, etc.

❌ npm packages not installed
   → Run: npm install
   → Then try building again

❌ Antivirus blocking
   → Temporarily disable antivirus
   → Or add project folder to exclusions


📋 QUICK TROUBLESHOOTING CHECKLIST
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Before building, verify:

□ Java installed? Run: java -version
□ Node.js installed? Run: node --version
□ In correct folder? Check: dir (should see package.json)
□ Packages installed? Check: node_modules folder exists
□ If not, run: npm install


💡 BEST PRACTICE
━━━━━━━━━━━━━━━

For the smoothest experience:

1. Install Java JDK 17
2. Restart computer
3. Open PowerShell in project folder
4. Run: npm install (if you haven't)
5. Run: .\build-apk-simple.bat
6. Wait 5-10 minutes
7. Get APK from: android\app\build\outputs\apk\debug\


🆘 STILL HAVING ISSUES?
━━━━━━━━━━━━━━━━━━━━━

Try these in order:

1. Use build-apk-simple.bat instead of build-apk.bat
2. Try PowerShell: .\build-apk.ps1
3. Try manual commands (see Solution 3 above)
4. Use GitHub Actions (see Solution 4 above)
5. Check you have Java: java -version
6. Check you have Node: node --version
7. Make sure npm install was run
