👋 WELCOME! LET'S BUILD YOUR APK
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Follow these steps to build your Android APK:


📋 STEP 1: INSTALL JAVA JDK (ONE-TIME SETUP)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

You need Java JDK to build Android APKs.

1. Download Java JDK 17:
   👉 https://adoptium.net/temurin/releases/

2. Run the installer
   ✅ Make sure to check: "Set JAVA_HOME variable"
   ✅ Make sure to check: "Add to PATH"

3. RESTART your computer after installation

4. Verify Java is installed:
   Open PowerShell and type: java -version

📖 Detailed guide: INSTALL_JAVA.md


🚀 STEP 2: BUILD YOUR APK
━━━━━━━━━━━━━━━━━━━━━━━━━

Once Java is installed:

1. Double-click: build-apk.bat

2. Wait 5-10 minutes

3. Your APK will be at:
   android\app\build\outputs\apk\debug\app-debug.apk


📱 STEP 3: INSTALL ON YOUR PHONE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Copy app-debug.apk to your Android device

2. Open the file on your phone

3. Tap "Install"

4. Grant Camera and Location permissions

🆘 NEED HELP?
━━━━━━━━━━━━

Common Issues:

❌ "JAVA_HOME is not set"
   → Install Java JDK (see INSTALL_JAVA.md)
   → Make sure to restart computer after install

❌ Build takes too long
   → First build: 5-10 minutes (normal)
   → Next builds: 2-3 minutes

❌ Scanner doesn't work in app
   → Enable Camera permission in phone settings

❌ GPS doesn't work in app
   → Enable Location permission in phone settings
