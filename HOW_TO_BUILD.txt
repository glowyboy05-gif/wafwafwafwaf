⚠️  FIRST TIME? YOU NEED JAVA JDK!
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

If you see "JAVA_HOME is not set" error:

1. Download Java JDK 17 from:
   https://adoptium.net/temurin/releases/

2. Install it (check "Set JAVA_HOME" during install)

3. RESTART your computer

4. Try building again

📖 Detailed instructions: See INSTALL_JAVA.md


🎯 EASIEST METHOD - JUST DOUBLE-CLICK!
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Find "build-apk.bat" in your project folder
2. Double-click it
3. Wait 5-10 minutes
4. Done!

Your APK will be at:
android\app\build\outputs\apk\debug\app-debug.apk


☁️ ALTERNATIVE - GITHUB ACTIONS (CLOUD BUILD)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Push code to GitHub
2. Go to "Actions" tab on GitHub
3. Click "Build Android APK"
4. Click "Run workflow"
5. Wait 5-10 minutes
6. Download APK from "Artifacts"

✅ No setup needed!
✅ Works on any computer!


💻 COMMAND LINE METHOD
━━━━━━━━━━━━━━━━━━━━━━━━

Open PowerShell and run:

    .\build-apk.ps1

Or manually:

    npm run build
    npx cap sync android
    cd android
    .\gradlew.bat assembleDebug


📱 INSTALLING ON YOUR PHONE
━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Copy "app-debug.apk" to your phone
   (via USB, email, cloud storage, etc.)

2. Open the APK file on your phone

3. Tap "Install"

4. If blocked, enable "Install from Unknown Sources"
   in your phone settings

5. Open Q-Control app

6. Grant Camera and Location permissions when asked
